# ingalls-weather-graphics

Auto-generated weather graphics for Ingalls Weather, published on a
schedule by [ingalls-weather-scripts](https://github.com/markingalls/ingalls-weather-scripts).
Each file is overwritten in place as new graphics are generated, so the
latest version is always at a stable URL (e.g.
`https://raw.githubusercontent.com/markingalls/ingalls-weather-graphics/main/tri_cities_7day_forecast.png`).
